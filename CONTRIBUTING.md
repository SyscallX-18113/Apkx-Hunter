# Contributing to Apkx-Hunter

Contributions are welcome! 🚀

We appreciate everyone who wants to help improve Apkx-Hunter, whether through code, bug fixes, new features, testing, documentation, or ideas.

## How to Contribute

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your work with a clear commit message.
5. Open a pull request explaining what you changed and why.

## Contribution Rules

- Keep your code clean, readable, and consistent with the existing project.
- Make sure your changes serve a clear purpose.
- Test your changes before submitting a pull request.
- Do not include credentials, API keys, personal data, or other sensitive information.
- Do not submit copied code without respecting its license and attribution requirements.
- Be respectful when discussing issues and reviewing contributions.
- For major changes, open an issue first to discuss the idea.
- Include relevant documentation updates when necessary.

## Bug Reports & Feature Requests

Found a bug or have an idea for a new feature? Open an issue in the repository with a clear description and steps to reproduce the problem, where applicable.

## Thank You!

Every contribution matters, and we appreciate your help in making Apkx-Hunter better.

**Let's build better open-source tools together!**
